# Ключи: что получить и куда вписать

Все ключи вписываются в файл `.env` в папке проекта. Чтобы его создать, скопируй `.env.example` и переименуй копию в `.env`.
В чат ключи присылать не нужно: скрипты сами прочитают их из файла.

Порядок важен только для первых двух пунктов: с ними уже появятся постеры, описания и оценки.

## 1. TMDB: постеры, описания, где смотреть (обязательно)

1. Зарегистрируйся на https://www.themoviedb.org/signup и подтверди почту.
2. Открой https://www.themoviedb.org/settings/api, нажми **Create → Developer**.
3. Форма: тип **Personal**, название, например, «Recommendations», адрес сайта можно указать `https://github.com/Lisht1`. Остальное заполни как угодно.
4. На странице API скопируй длинный **API Read Access Token**, а не короткий API Key.
5. Впиши в `.env`: `TMDB_TOKEN=...`

## 2. OMDb: оценки IMDb и Rotten Tomatoes (обязательно)

1. Открой https://www.omdbapi.com/apikey.aspx, выбери **FREE**, укажи почту.
2. В письме будет ключ и ссылка активации. **Перейди по ссылке**, иначе ключ не заработает.
3. Впиши в `.env`: `OMDB_KEY=...`

## 3. Telegram: чтение канала (обязательно)

1. Открой https://my.telegram.org, войди по номеру телефона (код придёт в Telegram).
2. **API development tools** → заполни App title и Short name (любые), Platform: Desktop.
3. Скопируй **App api_id** и **App api_hash** в `.env`:
   `TELEGRAM_API_ID=...` и `TELEGRAM_API_HASH=...`
4. Запусти в терминале (папка проекта):
   ```
   pip install telethon
   python scripts/telegram_login.py
   ```
   Скрипт спросит номер телефона и код из Telegram, а если включена двухфакторная защита, ещё и пароль. Всё это вводишь сам, прямо в терминале. После этого в `.env` появится `TELEGRAM_SESSION`.

> Сессия даёт доступ к твоему аккаунту Telegram. Не показывай её никому. Она хранится только в `.env` и позже в секретах GitHub.

## 4. Gemini: разбор новых постов и ИИ-подбор (можно позже)

1. Включи VPN (из Беларуси сайт не открывается).
2. Открой https://aistudio.google.com/apikey → **Create API key**.
3. Впиши в `.env`: `GEMINI_KEY=...`

Дальше VPN не нужен: ключ будет работать на серверах GitHub.

## 5. Кинопоиск: оценки Кинопоиска (необязательно)

1. Напиши боту https://t.me/kinopoiskdev_bot и получи бесплатный токен.
2. Впиши в `.env`: `KINOPOISK_KEY=...`

Без него не будет оценок Кинопоиска, и не подтянутся 18 ссылок на Кинопоиск из канала.
